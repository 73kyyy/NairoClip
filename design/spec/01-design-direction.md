# NairoClip 设计方向：灯下工作台（Bench Light）

> 本文是 NairoClip 的 UI/UX 设计基准，独立于任何历史 UI 文档。
> 设计对象：专业级本地 AI 视频剪辑软件（Android / iOS / 平板·折叠屏 / Windows / macOS）。
> 方法：先立设计哲学 → 反模板自检 → 定 token → 再落界面。所有界面数据来自真实引擎。

---

## 1. 设计哲学

**剪辑台不是仪表盘。** NairoClip 的使用者是在暗处盯着画面做判断的人：调色要准、字重要稳、
时间要看得到帧。界面的第一职责是**不干扰判断**，第二职责是**让"此刻在剪什么"永远不用找**。

因此整个产品建立在"工作台"隐喻上：桌面、台灯、胶片、量尺、手指。
不是 SaaS 卡片墙，也不是科幻 HUD —— 是木工台与剪片台的那种**精确与磨损感**：
面板之间用材质区分而不是投影堆叠；所有数字右对齐、等宽；所有时间刻度可数；所有动作可撤回。

三个不可让步的气质：

1. **暗、暖、低反差**（#141312 一类的暖墨），保证预览画面的颜色判断不被界面染色；
   高亮只留给"当前"，其余一律退后。
2. **测量感**：时间轴是有刻度的量尺，片段有齿孔与时长，播放头带读数。
   信息用结构表达（刻度、脊线、对齐），不用装饰性标签表达。
3. **诚实**：AI 不是魔法棒。每个 AI 动作都写明模型、耗时、联网/权益状态与失败原因；
   没有推理就明确不可用，绝不伪造进度与结果。

## 2. 反模板自检（本方案主动放弃的默认套路）

| 默认套路 | 本方案的选择 | 理由 |
|---|---|---|
| 奶油底 + 衬线大标题 + 陶土色强调 | 暖墨底 + 工业无衬线 + **钨丝琥珀**强调 | 剪辑在暗房，"台灯"是真实存在的器物语义 |
| 近黑底 + 荧光绿/朱红单一强调 | 暖墨 + 琥珀（动作）+ 青（信号/健康）+ 朱（错误） | 三色各有语义，不靠一种亮色制造"科技感" |
| 把内容切成同款圆角卡片 + 统一阴影 | 连续台面 + 发丝分隔线 + 材质差（哑光/拉丝） | 剪辑软件是长期驻留的工作面，不是落地页 |
| 全大写小标签 + 中点串元信息 | 中文小标签 + 等宽数字列对齐 | 中文界面里大写英文标签是外来装饰 |
| 到处淡入上滑 + 卡片悬停浮起 | 只保留"动作反馈"与一次性的面板展开 | 剪辑时任何多余动效都是干扰 |
| 一切 12px 圆角 | **切角（chamfer）**用于主按钮与播放头 | 切角是工具/军规仪器的语汇，且不与其他 App 撞脸 |
| 假进度条/假 AI | 全部接 C ABI 真实状态（`nc_ai_task_*`、`nc_export_run` 回调） | 产品红线 |

保留的一处"记忆点"：**播放头即量尺读数头**。它同时是位置、是读数、是抓取把手，
是用户在这个软件里最常碰到的那个零件。把大胆只花在这一处，其余保持安静。

## 3. Token

### 3.1 颜色

| 名称 | 值 | 用途 |
|---|---|---|
| `--ink-900` | `#0F0E0D` | 舞台/画布外围（最深） |
| `--ink-800` | `#141312` | 应用底色（暖墨） |
| `--ink-700` | `#191715` | 面板 |
| `--ink-600` | `#211E1B` | 抬升面/输入框 |
| `--ink-500` | `#2C2724` | 发丝线、轨道底 |
| `--paper` | `#E9E3DA` | 主文字（暖白，不用纯白） |
| `--paper-dim` | `#9C9287` | 次要文字 |
| `--paper-faint` | `#6B625A` | 三级文字/刻度 |
| `--tungsten` | `#F0A03C` | 动作、选中、播放头（台灯） |
| `--tungsten-deep` | `#B9721B` | 按下态、琥珀描边 |
| `--signal` | `#57C3B6` | AI/信号/健康（模型就绪、引擎可用） |
| `--alarm` | `#D8583C` | 错误、越界、离线条 |
| `--pro` | `#C9AE6A` | 权益标记（仅描边，不做填充） |

轨道类型用"脊线"表达，不做彩色胶囊：
视频 `--tungsten`、音频 `--signal`、字幕 `#A99BD6`、特效 `#8FA6C4`。

### 3.2 字体与字号

| 角色 | 字体 | 说明 |
|---|---|---|
| 界面/拉丁标题 | Instrument Sans | 工业感、字面收敛；避免 Inter/Roboto 的模板脸 |
| 时间码/数值/参数 | JetBrains Mono | 所有数字必须等宽、可对齐、可数帧 |
| 中文 | Noto Sans CJK SC | 与 Instrument Sans 字重接近；标题用 600 |
| 编辑性标题（首页/成片封面） | Noto Serif CJK SC | 只在"内容"上出现，与工具层形成对比 |

字号（桌面 / 移动）：11 / 12.5 / 14 / 16 / 20 / 26 / 34 / 48。
行高 1.45（正文）、1.15（数字与大标题）。数字一律 `font-variant-numeric: tabular-nums`。

### 3.3 间距、圆角、动效

- 间距基 4px；面板内边距 12/16；面板间距 1px 发丝线（不叠加 margin）。
- 圆角：控件 4px；面板 6px；**主按钮与播放头 0（切角 8px）**。
- 动效：状态 120ms `ease`；面板展开 240ms `cubic-bezier(.2,.8,.2,1)`；
  播放头**不做缓动**（位置必须即时对应手指/播放）。遵循 `prefers-reduced-motion`。

## 4. 布局三档

```
桌面 ≥1180 ─────────────────────────────────────────────
┌──┬───────────────────────────────────────────────┬────────┐
│导│ 顶栏：项目名 / 撤销重做 / 草稿 / 导出           │        │
│航├───────────────────────────────────────────────┤ 检查器 │
│栏│ 舞台（画面 + 字幕层 + 安全框）                 │ 320px  │
│56├───────────────────────────────────────────────┤ 参数   │
│px│ 走带：时间码 / 播放 / 入出点 / 缩放             │ 面板   │
│  ├───────────────────────────────────────────────┴────────┤
│  │ 时间轴：轨道头 176px ｜ 量尺 + 轨道（横纵滚动）          │
└──┴────────────────────────────────────────────────────────┘

平板/折叠 760–1180 ── 导航收为顶部图标条；检查器变为右侧 300px 或底部抽屉；
                       时间轴固定底部 42% 高；折叠屏按铰链分栏（左舞台/右检查器）。

移动 <760 ─────────── 顶栏（返回/项目/撤销）→ 舞台（9:16 满宽）
                       → 时间轴条（可横向滚动，2 轨可视）
                       → 工具页签（剪辑/音频/文字/特效/AI）+ 上下文抽屉（3 段吸附）
```

原则：**舞台永远可见**。任何面板展开都不得把预览挤到 40% 高度以下；
时间轴可以横向滚动，但播放头必须始终可见（超出视口时贴边显示方向指示）。

## 5. 组件规范

### 5.1 量尺与播放头
- 量尺刻度自适应：>60px/s 出帧刻度；>12px/s 出秒刻度；否则 5s/10s 主刻度带数值。
- 刻度数字 10px 等宽、`--paper-faint`；5 的倍数加长 2px。
- 播放头：1px 琥珀竖线 + 顶部切角标签（显示 `mm:ss:ff`）+ 底部抓取三角；
  命中区宽 24px（移动端 32px）。
- 吸附：片段边缘、标记、章节；按住 Alt 临时关闭吸附（状态栏提示"吸附已关闭"）。

### 5.2 片段
- 结构：齿孔边（上沿 6px，胶片语义）+ 缩略图平铺 + 底部信息条（名称 + 时长等宽）。
- 选中：1.5px 琥珀描边 + 右上角切角把手；不改变布局（避免跳动）。
- 状态：禁用 = 40% 透明 + 斜纹；锁定轨 = 斜纹；离线素材 = 朱色左边 3px + 图标。
- 转场：片段交界处的菱形/斜切块，长度即真实转场时长，可拖拽。

### 5.3 参数行
- 左标签（12.5px，`--paper-dim`），右数值（等宽 12.5px，`--paper`），中间滑杆。
- 滑杆轨道 2px，滑块 10×10 方形（工具感），双击标签恢复默认值。
- 取值超范围时数值变朱色并给出边界文案，不静默钳制。

### 5.4 AI 工具条目（诚实 AI）
每条包含：能力名、所需模型与体积、联网/权益标记、最近一次状态。
四种状态文案固定：可用 / 需下载模型（给出体积）/ 需 Pro / 引擎不可用（给原因）。
运行中显示真实进度（来自 `nc_ai_task_progress`），失败显示 `nc_ai_task_failure_text`，
提供"重试"与"取消"，绝不显示假进度。

### 5.5 导出
预设 → 规格（分辨率/帧率/体积/耗时，来自 `nc_export_estimate`）→ 权益提示
（`nc_would_clamp_export`）→ 真实导出进度（`nc_export_run` 回调）→ 完成卡片（路径/大小）。
导出中允许继续编辑；"极速模式"会提示将暂停编辑（`pauseEditing`）。

## 6. 状态与文案

- 空状态是**行动邀请**：一句话说明 + 一个主行动（导入素材 / 新建项目），不写抒情文案。
- 错误只说事实与下一步："素材文件不在了。重新链接或删除该片段。" 不道歉、不模糊。
- 破坏性操作：删除片段走撤销（不弹确认）；删除轨道/草稿需确认并写明影响范围。
- 长任务全部可取消、可离开页面（后台继续），回来能看到状态。
- 离线：顶栏出现朱色细条"2 个素材离线"，点击进入重链列表。

## 7. 性能与可访问性

- 预览按 `RenderQuality::previewQuality`（0.5 缩放 / 0.5 采样预算）取帧；
  拖动播放头时用低分辨率帧，松手后补一帧高质量。
- 代理媒体就绪时预览走代理，导出始终走原片（状态栏标注"预览：代理"）。
- 触控目标 ≥44×44；键盘可达：Tab 顺序 = 导航 → 顶栏 → 舞台 → 检查器 → 时间轴；
  快捷键：空格播放、S 分割、Del 删除、⌘/Ctrl+Z 撤销、⌘/Ctrl+Shift+Z 重做、M 标记。
- 对比度：正文 ≥ 4.5:1；琥珀仅用于 14px 以上或加粗文本。
